# OBS_Ticker
"Sportscenter" Style ticker overlay for OBS. Will allow to cycle through topics in real time with hotkeys

Script is not a typical OBS plugin. It uses the script section of OBS.
Requires Python 3.11. OBS does not currently work with anything newer than 3.12.

----------------------------------   Version 1.0 --------------------------------

Loads a list of topics read from a text file. File can be line separated and/or comma-separated.

Loading the file will create the .html filein the directory with the .py file

Topics will be loaded on an HTML/CSS coded overlay that will be loaded via Browser Source

Layout can be either vertical or horizontal

Topics can be scrolled in real-time using the next/previous buttons on the script UI
or by creating hoykeys
